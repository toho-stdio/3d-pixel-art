# Texel Splatting demo integration

This directory contains the Texel Splatting renderer source and a tea-stall demo integration derived from upstream Texel Splatting. The upstream baseline is commit [394d350f](https://github.com/dylanebert/texel-splatting/commit/394d350f91842779ed4c45760bd4ea9a07ce5c4c); the original MIT notice is retained in [LICENSE](LICENSE).

## Asset scope

This code-only release does not include production GLBs, reference images, TopoTopo graphs, previews, or production evidence. The demo can load an optional GLB from `public/production/` if a developer supplies one locally, but that directory is deliberately absent from this release. No production tea-stall scene is included or implied.

A small synthetic, multi-mesh GLB fixture is generated by `scripts/make-mock-glb.py` and labeled as mock in the demo. It is test/demo geometry only, not production geometry. To regenerate it:

```sh
python3 scripts/make-mock-glb.py
```

Use `?scene=mock` to select the fixture or `?baseline=1` for the original procedural baseline. If the default production scene path is unavailable, the demo falls back to the labeled mock/baseline scene.

## Run and verify

Requires Node.js and npm:

```sh
npm ci
npm test
npm run check
npm run dev
```

Open the local URL printed by Vite. The renderer requires WebGPU. Test coverage exercises the synthetic fixture and GLB parser transformations, materials, and error cases. No browser/device compatibility or production-asset verification is claimed.

`npm run build` creates a static Vite build. It may copy locally supplied sibling `../exports/*.glb` files into the ignored `public/production/` directory; production assets are not present in this repository.
